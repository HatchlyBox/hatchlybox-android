# Changelog

## 6.3 (2026-10-26)

- A welcome screen on first start, with the Hatchlybox logo: what it downloads and what leaves the phone in three short
  points, and one tap to accept Google's Android SDK licence and start. Nothing downloads before it.
- Signed with the Hatchlybox release key. A copy from before 6.3 has to be uninstalled once to install this one;
  updates install over it from now on.
- Settings has the privacy policy and the open-source licences.
- The local model asks you to accept Google's Gemma terms before it downloads.
- Hatchlybox is free software under the GNU AGPL 3.0.

## 6.2 (2026-10-26)

- Pairing works: a phone always tells the other device who it is.
- When the other device stops a sync, it says so in words.

## 6.1 (2026-10-26)

- Closing Library › Sync no longer closes the app.
- Pairing uses known ports (47197 to 47199), so a computer's firewall can let it in.

## 6.0 (2026-10-26)

- Pair nearby devices without a code: the other one accepts, both confirm the same six digits.
- Clearer pairing codes, and QR codes.
- Versions for other systems are made from the creation's other versions; their install scripts are checked;
  a version can be removed.

## 5.0 (2026-10-26)

- Hatchlybox is the one name everywhere.
- Hello World is Neon Run, the showcase game.
- Every new app gets its own icon.

## 4.1 (2026-10-25)

- The first release under the name Hatchlybox.
