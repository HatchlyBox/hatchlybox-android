# Security

Please report a security problem privately, not in a public issue: on the repository's **Security** tab, choose
**Report a vulnerability**. Say what's affected, how to reproduce it and what someone could do with it.

You'll get an answer within a week. Fixes come in the next release, and the report is credited unless you'd
rather not be named.

What counts: anything that lets a creation, an AI helper, a web page or another device on the network reach what it
shouldn't (keys, other creations, the user's files, the desktop page, a paired device's data), or run something the
user didn't ask for.
